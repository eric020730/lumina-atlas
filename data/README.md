# 課程情報資料

`course-intelligence.json` 是網站「最新課程情報」的唯一資料來源。頁面會依此檔案產生課程卡片、篩選結果、最近報名期限與查核狀態。

`video-learning.json` 是「影片學習室」的主要資料來源；若網路讀取失敗，頁面才會改用程式內的備援清單。每週排程可直接更新這份 JSON，不必修改頁面結構或互動程式。

`clinical-learning.json` 是「門診上手計畫」的課程、病例題、先修關係與官方學習護照領域來源。介面會依作答紀錄、熟練度、先修單元及到期複習日，動態產生今日課表。

更新原則：

- 優先使用衛福部、醫師公會全聯會與專業醫學會官方頁面。
- 原廠或診所課程需使用主辦單位官方來源，並清楚標示它是否具有特管時數。
- 無法核實的費用、名額或認證不得推測；使用「依主辦公告」或「待確認」。
- `creditStatus` 控制學分時間軸的顏色：`confirmed`（已明示）、`expected`（預計／待核定）、`unverified`（報名前確認）。
- 同一課程以主辦單位、日期及來源網址去重。
- 每次更新都要同步修改 `lastUpdated`、`sourceCount` 及各筆 `checkedAt`。
- 更新後執行 `npm run validate:data`。

影片更新原則：

- 優先主管機關、醫院評鑑機構、專業醫學會、具名專科醫師或有清楚醫療審稿資訊的教育頻道。
- 影片必須仍可播放，內容應服務零基礎觀眾，且不能把行銷宣稱當成醫學共識。
- 保留六週學習順序，涵蓋皮膚基礎、能量治療、注射概念與安全判讀；不收錄臨床操作參數或注射點位教學。
- 每筆更新 `checkedAt`，並同步更新 `lastUpdated` 與實際使用的 `sourceCount`。
- 更新後執行 `npm run validate:video`；正式發布前執行完整的 `npm run check`。

臨床動態課程更新原則：

- 先以衛福部皮膚科專科醫師訓練課程基準、訓練計畫認定基準及臺灣皮膚科醫學會評核資料建立能力範圍。
- 以常見門診與危險分流重排學習順序，不宣稱線上課程可取代合格住院醫師訓練、教師督導或真實病例量。
- 模擬病例不得計入官方學習護照病例／病症門檻；實際操作項目只提供學習目標與督導界線。
- 每個單元需有先修關係、至少三項目標、三項診間檢核、兩項危險徵象、四選一病例題及來源。
- 更新後執行 `npm run validate:clinical`。
